## Flowgraph Location

The `.grc` files should be placed under:

```text
gnuradio/VM1/
gnuradio/VM2/
```

Recommended names:

```text
gnuradio/VM1/vm1-vegan-internet.grc
gnuradio/VM2/vm2-vegan-internet.grc
```
